# geekbench6-installer-linux
One click installer for benchmarking using Geekbench 6


## Installation

Download the script and run:

```bash
curl -fL "https://raw.githubusercontent.com/leejy06/geekbench6-installer-linux/main/install-geekbench6.sh" -o install-geekbench6.sh
```
Run the script:
```bash
sudo bash install-geekbench6.sh
```
